# short-url-maker-JAVA-ANGULAR

# Requirements
-Node
-Java jdk and JAVA_HOME configured
-Maven installed and configured

# How to run
1. Download the project
2. Go to fe and run the command ng serve
3. Go to be and run mvn clean install
4. On be folder run java -jar target\shurl...-SNAPSHOT.jar
5. Go to http://localhost:4200 and try generating a short url
