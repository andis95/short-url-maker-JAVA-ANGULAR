# short-url-maker-JAVA-ANGULAR

# Requirements
1. Node
2. Java jdk and JAVA_HOME configured
3. Maven installed and configured

# How to run
1. Download the project
2. Go to fe and run npm install for node_modules
3. On fe run ng serve
4. Go to be and run mvn clean install
5. On be folder run java -jar target\shurl...-SNAPSHOT.jar
6. Go to http://localhost:4200 and try generating a short url
